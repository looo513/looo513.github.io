一、计算原理与程序实现

退水段流量服从线性水库消退规律，相邻两时段流量之比为常数，即流量消退系数：

Qt+1 = Cg · Qt　　　Cg = e−1/K，　K = −1 / ln Cg

只用一个观测点直接由 Qt+1/Qt 求 Cg 时，观测误差与资料代表性误差全部进入参数， 因此实际中取一组容量足够、代表性好的观测样本 (Qi,1, Qi,2)（i = 1,2,…,n）， 用最小二乘法估计：

Ĉg = Σ Qi,1 Qi,2 ／ Σ Qi,12　　　（式 2.36）

程序的设计思路（recession_coef.py，约 380 行，纯 Python + NumPy 实现）

  1. 数据层：把表 2.10 整理成 8 个序列（洪号 → 时段流量列表），缺测处自然截断；
  2. 样本层：build_samples(floods, q_lo, q_hi, t_lo, t_hi) 按洪号、流量区间、时段区间任意组合筛选观测对， 一种筛选条件即对应“一种样本选择方案”；
  3. 估计层：实现 3 类估计量——过原点最小二乘（式 2.36）、反算回归（Qt 为因变量）、 逐点比值平均（算术/几何/中位数），并计算 K、R²；
  4. 分析层：单点样本 → 单场样本 → 分水情/分段样本 → 留一法 → 蒙特卡罗随机抽样（每个容量重复 3000 次）， 定量刻画“样本选择”的影响；
  5. 输出层：控制台报表 + CSV 样本表 + 4 幅图 + 本报告，全流程一键复现。

五、样本选择对 Cg 估算的影响：机理小结

  • ① 误差放大机理。Cg 与 K 是“倒数对数”关系，Cg 越接近 1，dK/dCg 越大： Cg 由 0.97 变到 0.98，K 就从 33 变到 49 时段。 因此 Cg 的第 3 位小数都必须是可靠的，样本必须先把观测误差平均掉。
  • ② 观测误差机理。单点样本的 Cg = Qt+1/Qt， 两个流量各带 ±2% 的观测误差（水位流量关系、临时测流、整编误差）就能让 Cg 摆动 ±4%。 最小二乘相当于对 n 个样本做加权平均，误差按 1/√n 衰减，这才是要“成组取样”的根本原因。
  • ③ 代表性机理（物理成因）。退水曲线的上段是“地表+壤中流”快速退水，下段才是“地下径流”稳定退水， 两者 Cg 不同。样本若偏向某一流量级或某一退水阶段，估出的 Cg 必然系统性偏移（偏差，而非随机误差）。
  • ④ 权重机理。式(2.36) 以 Qt² 加权，大洪水、大流量样本主导结果。 样本构成中若缺少大洪水，Cg 会向低水段值偏移；若只有一场大洪水，则结果只反映该场特性。
  • ⑤ 估计式机理。以 Qt+1 为因变量和以 Qt 为因变量做回归，结果并不相同 （本例 0.9642 与 0.9649），样本点越分散差异越大， 说明样本的线性程度（R²）也影响估计式的选择。

六、结论与建议

  1. 用表 2.10 全部 186 个观测样本，按式(2.36) 估计得密赛流域 Cg = 0.964，K ≈ 27.5 时段（与教材 0.969 / 27.4 时段吻合），该值可作为本流域的代表性参数。
  2. 样本选择对 Cg 的影响是显著的、且常常是系统性的： 单点样本给出 0.886~0.994（K 相差 20 倍）， 单场样本给出 0.946~0.988， 分水情子集给出 0.946~0.984，只有多场次、全过程合并样本才稳定于 0.964。
  3. 率定取样三条要求：容量足够（本流域 ≥ 50 个观测对）、 覆盖完整退水过程（洪初/洪中/洪末、高/中/低水段都要有）、 包含不同量级与不同降雨时空分布的多次洪水（本例 8 场、Qmax 从 82 到 239 m³/s）。
  4. 检验时应注意：Cg 对结果极其敏感，宜用未参与率定的洪水做独立检验， 并以 K 的物力量级（本流域 20~30 时段）作为合理性校核，避免“数学最优、物理失真”。
